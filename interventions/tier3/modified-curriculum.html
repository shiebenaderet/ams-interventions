📖 Modified Curriculum & Assessment

⭐ Rating: ★★★★☆ 📚 Tier: 3 (Intensive) ⏱️ Time: Ongoing 👥 Group Size: Individual

What It Is

A change to what a student learns and is assessed on — not just how they access it. Modifications lower or change the learning standard itself and are typically specified in an IEP for students with significant cognitive disabilities.

Important distinction: An accommodation changes how a student accesses the same content (extended time, read-aloud, larger font). A modification changes what the student is expected to learn or demonstrate (fewer questions, simpler content, different standard). Modifications must be IEP-specified.
Used at AMS by: All core subjects list modified assessment, curriculum, and grading as a Tier 3 practice. Math, Social Studies, and ELA name it as a must-have.

Quality Implementation

✅ What TO Do

  • Read the IEP. Know exactly what is modified, to what degree, and why.
  • Coordinate with the case manager — they can help you interpret the plan
  • Modifications should maintain meaningful engagement with grade-level content when possible
  • Document what you're doing — modifications are legally binding and need a paper trail

❌ Red Flags

  • "Just giving less work" without IEP specification — that's neither modification nor accommodation, it's improvisation
  • Modifying for a student who doesn't have an IEP — lowers the ceiling unnecessarily
  • Teacher and case manager aren't communicating — student's plan varies by class
  • Grade on modified work presented as if it's on grade-level standard — misleading to family

Modification vs. Accommodation

FeatureAccommodationModification
Changes what's learned?NoYes
Changes how it's accessed?YesYes
IEP-required?IEP or 504IEP only
ExampleRead-aloud, extended timeFewer questions, different reading, alternate curriculum
GradingSame standardModified standard (documented)

Working with the Case Manager

  • Review the IEP at the start of each year and each semester
  • Ask specifically: "What does modification look like in my subject?"
  • Coordinate modified assessments in advance — don't wait until test day
  • Report progress at each IEP meeting; note what's working and what isn't

Monitoring Success

  • Student is making progress on their IEP goals
  • Modifications maintain meaningful engagement — student isn't just "doing easier work in the corner"
  • Family understands what modifications look like and how progress is measured
