Paraprofessional Support

What It Is

A dedicated paraeducator (para) assigned to support a specific student or small group across settings. Para support is typically IEP-specified and intended to increase student independence and access to curriculum — not to replace teacher instruction.

Used at AMS by: Math, Science, and PE/Health list para support as a Tier 3 practice. PE specifies 1-on-1 and small-group para support.

Quality Implementation

What TO Do

  • Para works with the student on the grade-level task when possible, not on a separate easier task
  • Teacher directs the instruction; the para supports access to it
  • Intentional fading — the goal is always more independence
  • Para is included in planning, at least briefly, so they know the day's objective
  • Regular check-ins between teacher and para (even 5 minutes counts)

Red Flags

  • The "velcro para" — constant shadowing that prevents peer interaction and independence
  • Para doing the work for the student rather than supporting them to do it
  • Student only talks to the para, never to peers or the teacher
  • Para used as a behavior manager instead of an instructional support
  • Teacher abdicates planning — "the para handles that student" is not a plan

Best Practices

PrincipleWhat It Looks Like
Support access, not replace instructionPara helps student track the teacher's directions, chunks the task, prompts participation — teacher is still the instructor.
Promote peer interactionPara steps back during partner work; helps student initiate with peers rather than relying on adult.
Fade strategicallyStart close, move to proximity (nearby but not adjacent), then to check-ins. Plan the fade explicitly.
Clear rolesTeacher: instruction, assessment, curriculum. Para: support, data collection, behavior support per the plan.

Common Pitfalls

Peers treat the student as "the para's kid"

Fix: Para sits one seat away during group work. Teacher structures peer tasks so the student has to interact with classmates, not just the para.

Para ends up doing the teacher's job

Fix: Teacher plans specific scaffolds the para can deliver — not open-ended "help him when he needs it."

No fading plan

Fix: In every IEP review, discuss reduction. Student should be moving toward more independence, not locked into 1:1 forever.

Monitoring Success

  • Student initiates with peers and teacher, not only with the para
  • Student can begin tasks independently (even if they need support to complete)
  • Support is fading over time — proximity, frequency, or duration is decreasing
  • Para data shows specific instances of student independence, documented for IEP review
